# HFinger 服务端指纹识别升级目标与范围

## 1. 文档目的

本文档用于定义 HFinger 下一阶段的产品目标、能力边界和非目标范围，作为后续规则库重构、引擎改造和社区协作的统一依据。

本次升级以“彻底升级”为原则，不考虑兼容旧版本规则格式，不保留对 `data/finger.json` 的运行时依赖。

## 2. 当前项目现状

当前版本具有以下特征：

- 指纹规则完全依赖 `data/finger.json`
- 规则模型仅支持 `cms/method/location/logic/rule`
- 当前匹配能力主要集中在：
  - `body` 关键词
  - `header` 关键词
  - `title` 关键词
  - `faviconhash`
- 结果模型仅包含：
  - `url`
  - `cms`
  - `server`
  - `statuscode`
  - `title`
- 支持主动模式和被动 MITM 模式

这套模型适合“基础 Web 指纹识别”，但已经不足以承载后续规划中的：

- 更细粒度的服务端技术栈识别
- 规则质量治理
- 证据化输出
- 社区 YAML 规则扩展
- 基础设施层识别

## 3. 升级总目标

HFinger 下一阶段的核心定位调整为：

> 一个面向安全测试场景的、专注服务端指纹识别的高性能引擎。

它的目标不是成为通用漏洞扫描器，也不是成为通用爬虫，而是帮助使用者快速、稳定、可解释地识别目标的服务端技术栈、基础设施和协议服务信息。

## 4. 识别对象范围

本项目后续识别对象限定为服务端资产，包含但不限于：

1. 网站与 Web 应用
2. Web 管理后台
3. API 服务
4. API 网关
5. Web 框架与后端框架
6. CMS
7. 中间件
8. WAF
9. CDN
10. 负载均衡
11. 反向代理
12. TLS/HTTPS 服务特征
13. 常见协议服务

## 5. 非目标范围

以下内容不作为本次升级主线：

1. APK/IPA 静态分析
2. 客户端程序二进制分析
3. 移动端 SDK 识别
4. 浏览器扩展式前端运行时分析
5. 通用漏洞利用与 POC 执行
6. 大规模资产发现
7. 通用目录爆破器
8. 通用爬虫平台

说明：这些能力可以作为外部工具联动对象，但不作为 HFinger 内核职责。

## 6. 竞品判断与产品定位

当前直接竞品以 `WhatWeb` 和 `xapp` 为主。

### 6.1 对 WhatWeb 的定位判断

WhatWeb 已经证明以下能力有明确价值：

- Web 技术栈识别
- 被动与激进程度可调
- 多种输出格式
- 丰富规则库
- 基于插件/规则扩展

但它主要聚焦 Web 技术识别，对现代服务端基础设施、证据模型、置信度治理、被动产品化并没有形成统一的现代化数据模型。

### 6.2 对 xapp 的定位判断

xapp 明确定位于 Web 指纹识别，并强调：

- 高性能规则引擎
- 自定义规则
- 社区共创
- 低误报

但它仍然更偏“Web 指纹工具”，而不是一个以服务端全景识别为目标的统一识别引擎。

### 6.3 HFinger 的目标差异

HFinger 不再只追求“另一个 Web 指纹工具”，而是追求：

1. 追平竞品在 Web 指纹识别上的主流能力
2. 向服务端基础设施层扩展
3. 提供证据化和置信度输出
4. 提供规则治理与测试能力
5. 保留主动模式与被动模式的统一识别体验

## 7. 运行时规则策略

本次升级采用以下规则策略：

1. 核心规则全部内置到程序中
2. 现有 JSON 规则全部迁移到新规则体系后再编译内置
3. 运行时不再依赖 `data/finger.json`
4. 后续社区规则与用户自定义规则采用 YAML 外置
5. 外置 YAML 规则在加载后进入统一运行时模型

这意味着：

- `finger.json` 将退出运行时职责
- 内置规则成为默认稳定能力
- YAML 成为后续社区协作入口

## 8. 本次升级的核心产品目标

### 8.1 准确性目标

- 优先降低误报
- 对规则强弱进行区分
- 提供排除条件能力
- 支持多证据合并判断

### 8.2 可解释性目标

- 每个识别结果都应能回答“为什么命中”
- 输出中应包含命中来源、命中规则、证据摘要和置信度

### 8.3 可维护性目标

- 规则可审查
- 规则可测试
- 规则可 lint
- 规则可社区贡献

### 8.4 工程性目标

- 默认开箱即用
- 不依赖外部规则文件才能运行
- 支持外置规则扩展
- 保持 CLI 使用习惯稳定

## 9. 本次升级的验收标准

若后续实现完成，至少应满足以下结果：

1. 二进制可在没有 `data/finger.json` 的情况下正常运行
2. 现有内置规则功能完整迁移到新引擎
3. 支持外置 YAML 规则加载
4. 支持规则 lint / test / compile 工作流
5. 支持基础证据字段输出
6. Web 指纹能力不弱于当前版本
7. 为后续 CDN/WAF/LB/TLS/协议识别预留可扩展结构
